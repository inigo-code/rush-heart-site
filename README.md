# Rush Heart

![Rush Heart showing finished downloads as cards](https://inigo-code.github.io/rush-heart-site/assets/rushes_history-wide.webp)

Website and downloads for Rush Heart, one of the [Heart Apps](https://inigo-code.github.io/). Download the app from [Releases](../../releases/latest).

The site is plain HTML and CSS, served by GitHub Pages. heart.css and heart.js are the shared Heart Apps files. The apps are free, all rights reserved.
